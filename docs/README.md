# Strixnova 文档

Strixnova 是由项目负责人作出决定、智能编码代理实施、程序校验确定性合同的本地工程治理工具。当前工程材料与运行可用性以[验证状态](engineering/validation-status.md)为准。

- [产品定义](product/definition.yaml)、[领域模型](domain/model.yaml)、[目标架构](architecture/model.yaml)说明当前设计候选。
- [工程政策](engineering/policy.yaml)与[方法来源](engineering/method-sources.md)说明工程约束及出处。
- [安装与首次使用](使用说明/installation-and-first-use.md)、[用户指南](使用说明/用户使用指南.md)、[命令手册](使用说明/Coding%20Agent%20命令手册.md)说明使用方式。
- [已记录工作与自身维护](使用说明/历史查询与自身升级.md)、[本地验证管理](使用说明/本地验证与临时产物管理.md)说明查询、恢复和开发证据管理。
- [隔离验收方案](engineering/agent-acceptance.md)与[行为要求目录](../tests/acceptance/guided-formation-cases.yaml)分别规定输入边界和待核验要求。

结构化材料中的修订、确认与保障状态必须按实际记录解释。程序核对结构和内容身份，不取得产品语义决定权。
