# 形成并维护现有决定的可读文档

负责人需要阅读文档时，与 PRD、SPEC 或领域文档专门资料一起读取。专门资料决定来源及
必须覆盖的条目，本文件提供共用写作和更新规则。

## 先绑定材料，再解释含义

调查请求范围、既有文档政策和实际来源文件。逐项记录路径、稳定身份、精确修订和真实确认及
采用状态。区分不可变 Git 版本与工作树候选；未提交来源还应记录内容指纹。尽量沿用项目现有
来源及索引惯例。元数据与覆盖索引保存在同一文档中，用来区分本阅读版的精确依据与后续修订。

未确认候选可以在原有确认之前被解释，但必须标明候选并绑定实际存在的来源。混合已确认和
候选来源时逐项区分；不能因一个来源有效，就把整份文档标为已批准、当前或就绪。读到文件
不等于证明它是项目已采用修订。

来源权威缺失时不得编造身份、修订或确认。形成请求按现有权威或方向起草路径，在已授权范围
准备必要候选。仅整理阅读版时说明能写什么并标明缺失。原始笔记可以支持来源明确的讨论草稿，
但不能冒充不存在权威的投影；不得只为排版阅读版建立 WorkItem。

## 保全会改变决定的内容

写作或判断对应章节前先读来源正文。路径表、指纹、标题和编号目录用于定位证据，不能说明
事实的条件和后果。沿集合引用读取原文，长文件分段读取，直到覆盖选定内容。用临时阅读和
覆盖清单保留进度，避免中断后把未读部分当成已覆盖。确定性清单和指纹使用可用工具取得，
工具不可用时不能编造。

来源较多时，按含义连贯的章节推进：读取有关正文、撰写解释、把来源项映射到真实锚点，
再回到原文比较。完成请求范围后再做跨章节复核。这是工作方法，不是新权威或持久的并行记录。

内部盘点专门规程要求的来源条目及输入中的重要主张。在紧凑覆盖索引中逐项说明：正文锚点已
表达、已引用具体来源，或者按本次阅读范围有理由地不展开。未决问题与冲突继续可见。稳定
身份来自实际权威，标题和段落顺序不创造新身份。

对每项主张判断：去掉它是否会改变产品决定、实现选择、验收判断或限制解释？如果会，就在
正文或明确来源引用中保留。摘要保留例外、阈值、排除项、解释取舍的被否决方案，以及观察、
假设和决定的差别。长输入需要认真提取，不能悄悄裁掉难处理内容；也不因引用就复制完整领域
或架构。

## 为读者的决定撰写

使用负责人的语言和项目统一术语，以连续正文解释产品与行为，关系适合时使用表格、具体流程
或小图。章节由实际内容决定。内部身份主要放来源和覆盖详情，只有帮助区分需求时才进入正文。
技术选择只解释影响决定的部分，正文不能变成字段清单、问卷、聊天记录或对下一个 Agent 的
指令。文字中性具体，避免宣传、装饰性标题、套路结论和嵌入文档的聊天式确认请求。

说明真实取舍、未知和下游可以依赖什么。不得补造能力、人物、数字、测量、批准或实现行为。
不完整但诚实的草稿可以有用；润色不能隐藏阻断决定。

## 分别复核内容与引用

先判断含义：是否忠实来源，是否显示重要选择、可观察结果和下一项决定需要的深度。按专门
资料的质量问题形成有位置、影响及纠正需求的发现。只审阅请求不修改文档或来源；排版修正
不授权改变产品含义。正式候选继续使用既有语义复核和确认合同，不增加文档批准。

再核对确定性事实：来源身份、修订、真实状态、文件、链接和锚点、未知或重复引用，以及每项
必需条目是否有明确处置。正文由 Agent 理解并撰写，不引入按关键词或字段生成正文的程序、
叙事中间模型或第二份语义记录。交付前重读来源，写作期间已变化时先协调，再声明当前有效。
临时检查只能证明这些事实，不能评分文章、推断缺失含义，或者证明删减理由和解释正确。

语义复核需要双向比较：从每项必需来源找到解释或有理由的处置，从文档的重要主张找回支持
它的原文。核对谁能决定、适用条件、例外与可观察后果。编号正确不证明对应句子正确，来源
中的未决事项为空也不证明阅读文档完整。未读材料和未完成覆盖必须作为限制披露；只有实际
读完、逐项处置并比较了含义的范围才能声称完整。

## 从实际来源更新

比较旧绑定与现在适用的来源，区分：

- 表达变化：改善阅读版，保持含义、来源文件、决定和运行状态不变。
- 含义变化：找到拥有事实的权威，形成或修订其候选，遵循原有确认和变更路径；改一段文字不
  等于接受了上游新修订。
- 来源变化：更新受影响章节与覆盖，检查交叉引用，说明哪些要求或决定改变。稳定身份遵循
  实际合同，退役含义只能作为清楚标记的历史，不能留作当前义务。

负责人纠正候选后，先修订受影响认识，再继续旧计划。冲突和待决定内容要说明下游影响，不能
静默选择。未变化来源可以保留原文，局部纠正不应整篇重写。状态或无关实施进度变化本身不能
证明规格含义变化，具体采用专门绑定规则。

现有请求已授权形成完整阅读版或修正它时，直接补齐范围内有来源依据的缺失说明。保留无须
修改的正确正文，但不能仅因遗漏较大，就把缺失章节推给新 WorkItem 或再次索取授权。
只有真实改变来源含义或请求范围时，才需要回到相应决定路线。

交付实际文档路径，并简要说明来源、覆盖、重要发现、未知与执行的检查。说明能支持哪项真实
决定，不只给完成标签。仅被授权写阅读版时，核对来源与运行文件保持不变。
