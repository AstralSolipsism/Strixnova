Usage: strixnova [OPTIONS] COMMAND [ARGS]...

  Strixnova：面向非专业项目负责人的本地软件工程治理。

Options:
  --version                Show the version and exit.
  --project-bindings FILE  明确本机绑定的 JSON 文件，格式见 context contract bindings。
  --help                   Show this message and exit.

Commands:
  activity     治理外部活动计划和回执；本命令不执行外部活动。
  alignment    准备、检查实现观察，授权外部捕获并写入实现对齐草稿。
  authority    逐类展示候选，或一次提交完整负责人决定包。
  cancel       取消事项，或处理取消后留下的本地工作。
  confirm      记录三个用户确认点之一。
  context      只读检查项目范围、读取内容或准备审阅资料；不采用配置或创建事项。
  delivery     推进工作区、实际结果、提交、本地集成或安全清理。
  history      只读查询事项历史，不受当前动作限制。
  intake       创建一个 WorkItem；不会扫描源码或创建 Git 分支。
  next         读取最小下一步；不指定事项时只列出未完成事项。
  setup-agent  安装轻量 Agent Skill；不修改配置、不安装 hook 或插件。
  status       分开读取目标、实现、验证、安装、交付、部署和运行状态。
  submit       提交 CurrentAction 要求的候选内容或明确判断。
  upgrade      显式预检、升级、查看或恢复 Strixnova 自身的本地运行数据。
  verify       运行工程方案中已选择的一项本地验证。
